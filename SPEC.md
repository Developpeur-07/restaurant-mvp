Objectif : Le client sait ce qu'il paie et quand il sera servi,
avant que la préparation commence.

Persona : Client sur place dans une pâtisserie/restaurant à Pointe-Noire.
Contrainte réseau : page légère, charge en 2s sur 3G.

User stories MVP (5) :
1. Client scanne QR → voit le menu avec prix garantis
2. Client choisit produits + entre numéro de table → confirme commande
3. Client voit "Votre commande sera prête dans ~15 min"
4. Client voit le statut changer en temps réel (reçu / en préparation / prêt)
5. Restaurateur voit commandes entrer + change statut en 1 clic

OUT OF SCOPE :
- Précommande depuis chez soi
- Paiement en ligne
- Gestion de stock
- Multi-restaurants

Critère de succès unique :
→ Temps moyen commande → service passe sous 20 min dans 3 restaurants.
